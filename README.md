# Handloom Weavers Collective

This project is a static website created for the **Handloom Weavers Collective** based on the provided design guidelines and content requirements.

## Features Included

- **Home 1 (index.html)**: Classic homepage featuring weaver stories and a welcoming layout.
- **Home 2 (home-2.html)**: Premium version of the homepage with an exquisite layout for bespoke and luxury collections.
- **About (about.html)**: Information about the identity, history, and expertise of the collective.
- **Products (products.html)**: Showcase of fabrics (Silk and Cotton) as per requirements.
- **Fair Trade (fair-trade.html)**: Dedicated page explaining fair trade practices and community support.
- **Contact (contact.html)**: Contact details and an enquiry form.

### Technical & Design Features
- **Responsive Design**: Adapts perfectly to desktop, tablet, and mobile screens.
- **Light & Dark Mode**: Persistent theme toggling (saved in localStorage).
- **LTR & RTL Support**: Layout direction switching built into the header (saved in localStorage).
- **Custom Branding**: Clean, earthy color palette matching the handloom theme with a custom SVG logo.
- **Pure HTML, CSS, JS**: No heavy frameworks required. Easy to maintain and edit.

## How to Run

1. Simply open the `index.html` file in any modern web browser.
2. Navigate through the site using the top navigation bar.
3. Use the icons in the top right to switch between Light/Dark mode and LTR/RTL text directions.
